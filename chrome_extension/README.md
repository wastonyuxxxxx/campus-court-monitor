# 网球场地空场提醒（Chrome）

这是一个只读监控扩展。它在当前 Chrome 登录态下打开校园预约系统的网球场详情页，读取网页周历；不会选择时段、填写预约信息或提交预约。

## 默认设置

- 监控五个场馆，默认不含张江学生活动中心。
- 默认监控周一至周日的全部时段；可按星期和时间范围筛选。
- 每分钟检查一次，只监控预约页面当前展示的未来一周。
- 新空场通过 Chrome/macOS 通知提醒。需要 Chrome 保持运行。

点击扩展图标可调整场馆、星期、时间范围和检查间隔，也可以停止监控。默认不勾选张江场馆，可以随时加入。开始和结束时间都留空表示全天。

弹窗顶部的「开放场次」列出最近检查读到的可预约场馆、日期和时间。点击任意一条可在新标签页打开对应场馆的预约周历。若本轮有读取失败，弹窗会标记这是最近记录，并显示失败原因。

## 安装

此目录需要作为未打包扩展加载到 Chrome：打开 `chrome://extensions`，开启“开发者模式”，选择“加载已解压的扩展程序”，然后选中 `chrome_extension` 文件夹。首次加载后点击扩展图标的“开始监控”。

Chrome 会显示扩展权限范围：它只申请本机通知、定时检查和本地设置，并只在 该校园预约平台的场馆详情页运行。扩展不会读取密码或手机号。

## 场馆详情页

详情页地址来自登录后网球场馆列表中的“去预约”入口。页面当前显示 08:00–22:00 的时段和每个场次的预约状态。若学校调整页面结构或场馆地址，扩展会在状态中显示读取错误，而不会尝试预约。
