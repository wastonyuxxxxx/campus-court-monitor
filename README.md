# 网球场地空场提醒

## 项目边界

本项目目前适配复旦大学（Fudan University）的校园体育场地预约平台，只读取其网球场详情页中当前展示的周历。场馆是否开放和时段状态以预约页面为准。

- 默认检查本北高速、国权路、南区、江湾综合体育馆和江湾室外体育场五个网球场。张江场馆可在设置中手动启用。
- 新安装后自动检查默认开启，每天 06:30–07:30 每 30 秒检查一次，其余时间每 30 分钟检查一次。可调整高频时段、检查频率、场馆、星期和时间范围，也可立即手动检查一轮。
- 扩展复用当前 Chrome 登录会话，检查预约页面当前显示的未来一周，并通过 Chrome/macOS 本机通知报告新开放场次。
- 自动化只打开场馆页面、读取周历和发送提醒。预约须知、选择场次、填写预约信息及最终提交都由使用者完成。
- 自动检查需要 Chrome 保持运行且电脑不休眠。页面读取失败时，扩展显示错误状态和最近一次读取记录。

## 安装

1. 在 Chrome 打开 `chrome://extensions`。
2. 开启「开发者模式」，选择「加载已解压的扩展程序」。
3. 选择本仓库的 `chrome_extension` 文件夹。
4. 点击扩展图标查看空场，或点击「立即检查」执行一轮检查。

Chrome 会显示扩展权限。扩展只申请定时检查、本地设置和通知权限，并只访问预约平台的场馆详情页。

更多操作说明见 [Chrome 扩展说明](chrome_extension/README.md)。
